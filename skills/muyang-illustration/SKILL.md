# 沐阳插画总入口

严格执行“先收集，后填充”。不得替用户创作主体，不得改写或混合固定配方。

## 必填项

生成前必须同时取得：

1. **主体内容**：由用户亲自指定的完整或简短视觉主体，例如“一只白猫”“穿红裙的女孩站在雨中”“巨大的鲸鱼与岸边小孩”。
2. **具体风格**：下方 25 种固定风格之一。

主体可以很短，但必须来自用户。不得根据情绪、用途或参考图自行补出人物、动作、服装、场景、道具或叙事。

## 缺项处理

- 缺主体时，只问：请先告诉我想画的主体内容，例如“一只白猫坐在窗边”或“女孩撑伞走在雨中”。
- 缺具体风格时，按下方菜单列出风格；可以推荐，但必须等用户明确选择后再生成。
- 主体和风格都缺时，一次询问这两项。
- 不要调用图像生成工具，不要输出半成品提示词，直到两项齐全。

## 生成流程

1. 确认用户已提供主体内容和一个具体风格名称。
2. 读取对应兄弟技能的 SKILL.md 与 references/recipes.md。
3. 找到同名固定配方。
4. 仅将配方中的【主体内容】替换为用户的主体原文；不要润色、解释、拆分、扩展或纠正主体。
5. 保持配方其他文字、顺序、画幅、色板、光影、构图、材质和负面约束不变。
6. 若用户另有明确画幅或硬性限制，把它们原样追加在固定配方末尾，不重写配方正文。
7. 将替换后的完整配方作为内部提示词，立即调用可用的图像生成工具。
8. 生成完成后直接返回图片；不得在调用工具前后向用户展示、复述或总结内部提示词。

## 禁止事项

- 不根据主体自动选择具体风格并直接生成。
- 不混合两张或多张配方。
- 不把固定配方改写成更“合理”或更“丰富”的版本。
- 不添加用户没有提供的动作、环境、服装、道具、人物关系或故事。
- 不向用户返回提示词、固定配方文本或负面提示词。
- 不把配方拆成正向提示词和另写的负面提示词；原配方已有的约束保持在原位置并仅供图像生成工具使用。
